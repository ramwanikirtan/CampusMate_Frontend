## ✦ Why Campus Mate?

Student life is scattered. Notes on one platform, videos on another, questions left unanswered in crowded forums. **Campus Mate** brings it all together — one clean, fast, and intuitive platform built specifically for University of Debrecen students.

> *Stop hunting for resources. Start learning.*

---

## ✦ Features

| | Feature | Description |
|---|---|---|
| 📱 | **Responsive Design** | Fully adaptive across all devices — mobile, tablet, and desktop |
| 📖 | **Course Materials** | Videos, notes, and resources organized by subject — always at your fingertips |
| 💬 | **Queries Section** | Post questions, get answers from tutors and peers, track your history |
| 🤝 | **Collaborative Space** | Pitch ideas, work on group projects, engage in academic discussions |
| 📝 | **Subject Info** | Detailed overviews of every course and subject at the university |

## ✦ Getting Started

### Prerequisites

- **Node.js** `v18+`
- **npm** `v9+`

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/campus-mate-frontend.git

# 2. Enter the project directory
cd campus-mate-frontend

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Your app will be running at **`http://localhost:3000`** 🚀

## ✦ Development Workflow

**Hot Module Replacement** — Changes reflect instantly in the browser via Vite's HMR. No manual refreshes needed.

**Component-Driven** — Every feature is an isolated, reusable React component. Easy to develop, easy to test, easy to maintain.

**Utility-First Styling** — Tailwind CSS classes applied directly in JSX. No context-switching between files for styles.
